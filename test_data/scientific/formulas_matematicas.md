# Fórmulas Matemáticas Fundamentales

## Álgebra

### Ecuación Cuadrática
Para ax² + bx + c = 0:
x = (-b ± √(b² - 4ac)) / 2a

### Binomio de Newton
(a + b)ⁿ = Σ(k=0 to n) C(n,k) · aⁿ⁻ᵏ · bᵏ

## Cálculo

### Derivadas Básicas
- d/dx(xⁿ) = n·xⁿ⁻¹
- d/dx(eˣ) = eˣ
- d/dx(ln x) = 1/x
- d/dx(sin x) = cos x
- d/dx(cos x) = -sin x

### Integrales Básicas
- ∫xⁿ dx = xⁿ⁺¹/(n+1) + C
- ∫eˣ dx = eˣ + C
- ∫1/x dx = ln|x| + C

### Teorema Fundamental del Cálculo
∫[a,b] f(x)dx = F(b) - F(a)

## Geometría

### Áreas
- Círculo: A = πr²
- Triángulo: A = (b·h)/2
- Esfera: A = 4πr²

### Volúmenes
- Esfera: V = (4/3)πr³
- Cilindro: V = πr²h
- Cono: V = (1/3)πr²h

## Trigonometría

### Identidades Fundamentales
- sin²θ + cos²θ = 1
- tan θ = sin θ / cos θ
- sin(2θ) = 2·sin θ·cos θ

## Probabilidad y Estadística

### Media
μ = (Σxᵢ) / n

### Desviación Estándar
σ = √(Σ(xᵢ - μ)² / n)

### Distribución Normal
f(x) = (1/σ√(2π)) · e^(-(x-μ)²/2σ²)
