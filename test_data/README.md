# Test Data - Archivos de Prueba

Esta carpeta contiene archivos de prueba diversos para el proyecto DistriSearch.

## Estructura

```
test_data/
├── documents/          # Documentos de texto variados
│   ├── articulo_tecnologia.txt
│   ├── receta_paella.txt
│   ├── historia_roma.txt
│   ├── poema_neruda.txt
│   ├── manual_python.md
│   ├── datos_ciudades.csv
│   └── config_ejemplo.json
│
├── scientific/         # Documentos científicos y técnicos
│   ├── paper_machine_learning.txt
│   ├── fisica_cuantica.txt
│   ├── biologia_celular.txt
│   ├── estadisticas_clima.csv
│   ├── formulas_matematicas.md
│   └── experimento_datos.json
│
└── misc/              # Archivos diversos
    ├── contrato_ejemplo.txt
    ├── correo_profesional.txt
    ├── lista_tareas.md
    ├── inventario.csv
    ├── log_servidor.txt
    ├── notas_reunion.txt
    ├── sample_data.xml
    └── binary_sample.dat
```

## Tipos de Archivos

- **TXT**: Texto plano en español e inglés
- **MD**: Markdown con formato
- **CSV**: Datos tabulares
- **JSON**: Datos estructurados
- **XML**: Datos con marcado XML
- **DAT**: Archivo binario de ejemplo

## Uso

Estos archivos están diseñados para probar:
- Indexación de documentos
- Búsqueda semántica
- Procesamiento de diferentes formatos
- Vectorización de texto
- Particionamiento de datos

## Contenido Temático

Los documentos cubren diversos temas para probar la búsqueda semántica:
- Tecnología e IA
- Cocina y recetas
- Historia
- Literatura y poesía
- Programación
- Ciencia (física, biología, matemáticas)
- Documentos empresariales
- Logs de sistema
